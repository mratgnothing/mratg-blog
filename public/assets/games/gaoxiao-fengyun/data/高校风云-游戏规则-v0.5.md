## 一、游戏概述

### 1.1 背景

时间从 **1990年** 开始(可选变体:1980年开局,见 12.4)。每位玩家执掌一所中国知名高校,在六十年的时代浪潮中做出战略抉择:押注哪些学科赛道?抢夺哪些人才?与谁结盟?如何应对"房地产雪崩""人工智能崛起""疫情蔓延"这样的时代巨变?

你的目标只有一个:**让你的学校成为公认的世界一流大学**——即声望率先达到本校档位对应的胜利线;若到 2050 年无人登顶,则按"声望 − 自身胜利线"比较相对成就。

### 1.2 基本参数

| 项目 | 参数 |
|---|---|
| 游戏人数 | 3~6 人 |
| 游戏时长 | 90~150 分钟 |
| 时间跨度 | 1990 → 2050,共 6 个时代(每时代 = 10 年) |
| 胜利方式 | 达到本校档位胜利线立即获胜:领跑 **112** / 劲旅 **86** / 蓄力 **80** ⚙;或 2050 年按"声望 − 自身胜利线"结算 |

### 1.3 设计基调

- 高校之间**不存在"攻击/消灭"**。冲突通过竞争性机制体现:人才竞价、挖角、评估排名、项目竞标、院系调档拉锯。
- **学科组合 = 投资组合,时代事件 = 市场波动**。这是游戏的灵魂:没有永远的强势学科,只有踩对时代节拍的学校。
- **理工科是声望的主干道,文科是政策与韧性的护城河**——权重不同,但都通向胜利(§11.1)。
- 弱开局学校有专属的"逆势崛起"路径,开局强弱 ≠ 游戏胜负。

## 三、核心概念与资源

### 3.1 四种资源 + 一条计分轨

| 资源 | 现实对应 | 获取方式 | 用途 |
|---|---|---|---|
| **经费 💰** | 年度预算、拨款、捐赠 | 预算阶段收入、拆分院系、事件 | 万能货币:建院系、竞价人才、上项目、加急调档 |
| **学术点 🔬** | NSC 论文、科研产出 | 理/工/医类院系产出 | 升级院系、竞标项目、招人才 |
| **生源力 🎓** | 录取分数线、招生吸引力 | 评估获奖、人才入驻、新工科、事件 | 决定行动顺位；达到3/6/9时分别提供1个“生源加成”名额(见下) |
| **政策力 🏛** | 部委关系、区位红利 | 文/法类院系、区位、事件 | 稀有资源:买保险、偷看事件、签联盟、防挖角、挽留院系 |
| **声望 ⭐(计分轨)** | 综合排名 | 见 11.3 声望来源总表 | 原则上只增不花;**唯一例外:挽留调档中的院系可以消耗声望(§7.6)**——"面子换里子" |

### 3.2 生源加成 ⚙

- 生源力达到 **3 / 6 / 9** 时，预算阶段分别获得 1 / 2 / 3 个“生源加成”名额；9以上不再增加。
- 每个名额选择 **1 个不同院系**，令该院系本次预算自动产出的任意一种其本来能够产出的资源 +1。
- 同一个院系同一预算阶段最多吃 1 个生源加成；只增强预算自动产出，不增强“科研攻关”等额外产出。
- 若生源力在预算开始时低于某阈值，对应名额立即失效；无需额外永久标记，预算结算完即结束。

### 3.3 资源循环(引擎)

```
经费💰 ──建设──▶ 院系 ──产出──▶ 学术点🔬/政策力🏛
   ▲                                   │
   │                                   ▼
 预算收入 ◀── 声望⭐/认证 ◀── 评估 ◀── 人才+院系等级
```

### 3.4 区位标签

每张高校牌印有区位标签之一:**一线 / 新一线 / 中西部 / 东北 / 港澳**。区位不是数值,而是事件与政策的作用对象(例:「西部大开发」利好中西部,「东北振兴」利好东北,港澳高校经费机制特殊)。

### 3.5 学科八门类(v0.2 重划)

| 门类 | 涵盖示例 | 备注 |
|---|---|---|
| **文** | 中文、历史、哲学、外语、艺术 | |
| **法** | 法学、政治学、社会学、教育学 | 广义社科 |
| **理** | 数学、物理、化学、天文、地学 | |
| **农** | 农学、林学、生态、海洋 | |
| **医** | 临床、基础医学、药学、公卫 | |
| **商** | 经济、金融、管理 | |
| **传统工科** | 土木、机械、化工、电气、电子信息 | 开局主力工科 |
| **新工科** | 人工智能、新能源、集成电路、生物医学工程、智能制造 | **开局不存在,随时代解锁(§7.5)** |

每张院系牌、人才牌、多数事件牌都挂靠一个门类。

## 四、游戏设置(开局)

1. **选校**:洗混首发 48 张高校牌,每人发 3 张,秘密选 1 张亮出,余牌回盒。
   *(教学局建议直接指定,可采用附录 C 的 11 校。)*
2. **领取开局配置**:按高校牌所示获得初始经费、初始院系(从对应门类的等级Ⅰ牌中取)、初始声望。开局院系中，**只有门类属于本校两个核心门类的院系放置核心标记**；非核心门类的开局院系保持非核心(§7.4)。
3. **布置市场与牌堆**:
   - 院系市场:翻开 6 张院系牌成一排(等级Ⅰ、Ⅱ混合,**不含新工科**);
   - 新工科区:Ⅰ级6张、Ⅱ级4张分开扣置为解锁池，Ⅲ级2张单独作为升级池;第3时代起按 §7.5 解锁;
   - 人才市场:翻开 3 张讲席教授;
   - 政策市场:洗混 24 张政策牌，翻开 4 张形成公开市场;
   - 事件堆:6 堆按时代排好,第 1 时代堆置于"1990s"格;
   - 国家重大工程：按时代将 60 张牌分成 6 组，每组 10 张；再按“基础科学 / 工程技术 / 生命资源 / 人文治理 / 交叉战略”五赛道各分 2 张，分别洗混扣置。
4. **确定首位玩家**:初始生源力最高者获得"招生办主任"标记;平手时开局声望低者优先。
5. 声望轨的 **80 / 86 / 112** 格分别放置蓄力、劲旅、领跑胜利线标记;每位玩家在校牌旁放置与本校档位相同的胜利线提示标记。

## 五、时代与回合结构

游戏共 **6 个时代**:1990s、2000s、2010s、2020s、2030s、2040s。每个时代按以下顺序进行:

### 阶段① 预算阶段
- 每位玩家获得:**基础拨款 3💰 ⚙ + 每枚双一流认证 1💰 + 高校技能/事件修正**;各院系执行自动产出。
- **调档推进**:所有"调档中"的院系自动 +1 调档刻度(§7.6)。
- 港澳区位学校不领基础拨款,改为执行其校牌上的特殊经费规则。

### 阶段② 事件与立项阶段
- 翻开本时代事件堆顶 **2 张**事件牌 ⚙,依次结算,持续性事件平放在桌面中央直至到期。
- *(第 1 时代仅翻 1 张,让玩家热身。)*
- 随后进行本时代国家重大工程立项（§10.2）：基础科学、工程技术、生命资源、人文治理四赛道各随机翻开 1 张；5~6 人局再从交叉战略赛道随机翻开 1 张。若时代事件明确“指定立项某一工程”，则指定工程优先替换同赛道原项目；若 3~4 人局指定的是正常不开放的 E 交叉战略项目，则它改为替换本时代 B 工程技术项目，开放项目总数仍保持 4 个。
- **初始申报窗口 ⚙**：项目全部翻开后，按本时代行动顺序，每名玩家获得一次不消耗 AP 的“初始申报机会”，可向 **1 个自己具有主门类/协同门类资格**的开放工程投入至少折算为 1 个有效点的资源。可以放弃，未使用机会不能带入行动阶段。联盟成员可把各自的初始申报投入同一个联盟竞标单位。
- **零匹配保底 ⚙**：若某玩家在本时代全部开放工程中一个主门类/协同门类匹配都没有，可把上述免费机会改为一次“保底协作申报”：按社会协作单位规则向 1 个工程投入至少 `3💰=1 有效出资点`。该玩家仍无牵头资格、不能使用倍率；只有零匹配玩家可用，且仍计入每时代最多 2 项工程的上限。

### 阶段③ 行动阶段
- 按生源力从高到低确定行动顺序(平手看"招生办主任"标记及其顺时针方向)。
- 每人 **4 个行动点(AP)** ⚙,轮流每次执行 1 个行动,直到所有人 AP 用尽或声明跳过。行动清单见第六节。

### 阶段④ 国家重大工程结算
- 按项目编号从小到大逐一结算本时代全部开放工程：计算有效出资、确定前二、分配声望并发放牵头/参与奖励，详见 §10.2。
- 工程的永久平台与强度奖励先落位，因此可影响紧随其后的本时代评估。

### 阶段⑤ 评估阶段(仅第 2、4、6 时代末,即 2010、2030、2050 年)
- 进行**学科评估**与声望结算,详见第十一节。

### 阶段⑥ 时代推进
按固定顺序进行状态重置，再刷新市场：
1. 收回高校牌、公共模块与智库通道上的本色“已用”标记；
2. 所有横置人才牌转正；
3. 弃置写有“本时代”的持续政策，移除仅持续到时代结束的院系修正与市场保留方块；
4. **永久国家重大工程奖励不清除**：若奖励绑定某院系，将对应工程牌的标题/奖励区露出并压在该院系牌下作为实体提醒；
5. 弃掉本时代未触发的事件牌，刷新院系市场与人才市场(各弃掉最旧的一半并补满)，第 3 时代起追加新工科解锁(§7.5)；
6. 检查是否有人达到**本校档位胜利线**(是则按 §12.1 立即结束)。

完整桌面记录规范见《高校风云/高校风云-玩家参考与标记规范-v0.5.md》。

## 七、院系系统

### 7.1 院系牌构成

```
┌─────────────────────┐
│  计算机科学系 [传统工科]│  ← 名称 + 门类标签
│  等级 Ⅱ  ●●○        │  ← 等级(Ⅰ/Ⅱ/Ⅲ)
│  产出:2🔬            │  ← 预算阶段自动产出
│  人才槽:▢▢          │  ← 可镶嵌人才数(=等级)
│  强度:4             │  ← 评估阶段比较用基础值
└─────────────────────┘
```

- **强度** = 牌面基础值 + 镶嵌人才加成 + 核心/认证/工程平台等永久修正 + 事件/政策临时修正。每枚放在该院系上的“双一流认证”固定提供 **+1 强度**，每个院系最多 1 枚认证。评估阶段按门类汇总强度。
- 院系牌还带有“土木、能源、AI、芯片、海洋、种业”等**方向标签**。方向标签不改变八门类归属，只用于特定事件、人才、国家重大工程与高校技能的精确匹配。96 张完整牌表见《高校风云/高校风云-院系牌全库.md》。

### 7.2 八门类产出倾向 ⚙

| 门类 | 产出主轴 | 特性 |
|---|---|---|
| 理 | 🔬 高 | 学术点主产地,国家重大工程的基础科研主力 |
| 传统工科 | 🔬 + 💰 | 横向课题带来经费,产出均衡;事件周期性大起大落 |
| **新工科** | 🔬 极高 | 造价 +1💰;**首个新工科院系使生源力 +1**(热门专业虹吸);易受"内卷"类事件影响 |
| 医 | 🔬 + 💰 | 附属医院稳定收入,负面事件抗性中等 |
| 商 | 💰 高 | 经费引擎;受经济类事件波动最大 |
| 文 | 🏛 + 少量⭐ | 每次评估若持有等级Ⅱ以上文科院系 +1⭐(文化影响力) |
| 法 | 🏛 高 | 政策力主产地——稀缺资源的唯一稳定来源 |
| 农 | 产出低但造价低 | **多数负面事件不影响农林**;评估强度性价比高 |

> 设计意图:理工医是"声望主干道"(见 §11.1 的计分倾斜),文法是"政策护城河"(政策力垄断),商是"现金奶牛",农是"抗周期资产"。八门类各有必买理由。

### 7.3 院系数量上限

每位玩家的院系区上限 = **6 格** ⚙,高校技能可修正。上限逼迫玩家做取舍——全面铺开还是重点建设,这就是"综合性大学 vs 特色型大学"的路线分歧。

### 7.4 核心院系(参考:钢铁雄心4 核心领土)

- 每张高校牌标注 **2 个核心门类**(该校的立校之本)。
- 开局时，**只有属于这两个核心门类的开局院系**获得核心标记；非核心门类的开局院系不获得核心标记。
- 此后你在核心门类下**自行建设**的院系，可在建成时免费放置核心标记；通过调档买入的院系即使门类匹配，也永远不能变为核心。
- 核心院系规则:
  1. **不可被调档转出**——任何交易、事件都不能使你失去核心院系(拆分、合并仍可自愿进行,合并所得延续核心身份);
  2. 核心院系中的人才被挖角时,**首次防御免费**(不花🏛);
  3. 核心院系强度 +1(主场底蕴)。
- 非核心门类的院系永远不能获得核心标记——买来的、转型来的热门院系始终是"可流动资产",这是调档博弈的基础。

### 7.5 新工科:解锁与转型(v0.2 新增)

新工科代表 1990 年尚不存在或未成气候的学科方向。规则:

1. **分级锁定**:12 张新工科院系开局全部锁定，但分成三个区域：Ⅰ级 6 张、Ⅱ级 4 张作为“解锁池”，Ⅲ级 2 张单独作为“升级池”，**Ⅲ级永不直接进入市场**。
2. **时代解锁**:自第 3 时代(2010s)起，每个时代推进阶段解锁 2 张 ⚙：2010s、2020s 优先从Ⅰ级池随机翻牌；2030s 起可按“1 张Ⅰ + 1 张Ⅱ”解锁，Ⅰ级池耗尽后改从Ⅱ级池补足。解锁牌进入院系市场。
3. **事件解锁**:部分事件牌可提前或额外解锁特定方向的新工科牌(如「人工智能崛起」:将尚未解锁的 AI 类Ⅰ/Ⅱ级院系翻入市场,且本时代其建造费 −1💰)。Ⅲ级牌仍只能通过升级/合并/特殊效果取得。
4. **工科转型**(行动 #5):传统工科院系可半价转型为同等级新工科——这是老牌工科强校的护城河:别人从零建设,你直接"学院改名、班底平移"。
5. **先发与内卷**:新工科产出最高、自带生源吸引,但相关人才竞价底价会随事件翻倍,且"赛道内卷"类事件专门打击持有新工科最多的玩家。早买吃红利,晚买躲风险,全押挨内卷——押注节奏本身就是决策。

### 7.6 跨校调档:院系转移机制(v0.2 重做,参考:文明6 忠诚度)

玩家间的院系交易不再是"一手交钱一手交货",而是一场**跨越数年的拉锯**:

**发起(行动 #13)**
- 买卖双方协商价格(💰/🔬/政策牌任意组合,可分期);买方额外支付 **2🏛 调档费**给银行。
- 目标必须是**非核心**院系,可连同镶嵌人才一并转移。
- 在该院系上放置调档轨:目标 **3 刻度** ⚙,当前 0。

**调档期**
- 每个预算阶段自动 +1 刻度(时间流逝);
- 买方可用行动 #14 **加急**:2💰 = +1 刻度,每时代限 2 次(砸钱挖整建制团队);
- 卖方可用行动 #15 **挽留**:花 **1⭐ 或 2🎓** = −1 刻度(不低于 0),每时代限 1 次——**用声望挽留是全游戏唯一"花声望"的行为**:公开宣示重视、给编制给待遇,面子换里子;
- 调档期间院系仍属卖方,但**产出减半**(军心浮动),强度评估时 −1。

**结算**
- 刻度满 3:院系(连同人才、认证)移交买方,买方付清尾款。移交后该院系**永不成为买方核心**。
- **流拍**:若发起后经过两个完整时代仍未满刻度,交易作废——买方收回已付价款的 50%,院系留卖方并恢复产出。挽留方等于用声望和时间"熬走"了买家。

**事件联动**
- 「教育部院系大调整」(附录A):生效时代内,发起调档免调档费,目标刻度降为 **1**,且不可被挽留——行政力量面前,拉锯戏码暂停。这是全场院系大洗牌的窗口期,提前囤 🏛 和现金的玩家吃满红利。

**设计意图**:调档期让交易从"瞬间结算"变成**持续数轮的公开事件**,全桌都看得到、都能围绕它博弈(第三方可以趁卖方声望受损时抢评估名次);挽留花声望制造了"为了留住王牌院系牺牲排名"的痛苦抉择,正是现实中高校保学科的写照。

### 7.7 拆分/合并/调档的战略含义

- **合并**是长线投资:两张弱牌换一张强牌,评估口径下更占优。
- **拆分**是救急与止损:利空事件砸中你的门类时,拆分套现离场。
- **调档**是风险转移与赛道置换:你不看好的资产可能是别人技能体系里的拼图;而"永不成为买方核心"意味着买来的院系还可能被第三方再挖——流动资产永远在流动。

## 八、人才系统

### 8.1 三档人才

| 档次 | 数量 | 典型加成 ⚙ | 备注 |
|---|---|---|---|
| 讲席教授 | 18 | 所在院系主产出 +1；少量“教学型”入职另 +1🎓 | 常规供给，底价约 2 |
| 杰青/长江 | 12 | 主产出 +1、强度 +2，并带一个轻量方向特性 | 第 2 时代起进入市场，底价约 4 |
| 院士/学部委员 | 6 | 强度 +3、入职 +2⭐，并带唯一特效 | 第 3 时代起进入市场，底价约 7 |

人才牌标有**门类与方向标签**。放入同门类院系 → 全额生效;放入异门类 → 数值效果减半(向下取整),依赖方向匹配的唯一特效不能触发。新工科人才可无损放入传统工科院系(反之减半)——转型期的人才通用性。36 张完整牌库见《高校风云/高校风云-人才牌全库.md》。

### 8.2 招募(竞价)

1. 发起者指定人才市场中 1 张牌并给出起价(≥ 牌面底价,用 💰+🔬 任意组合支付)。
2. 从发起者起顺时针轮流加价或弃权,弃权后不得再进入本次竞价。
3. 最后留下者支付出价,将人才放入自己一个空人才槽。
4. **发起者保护**:若发起者最终未拍得,获得 1🎓 补偿("被撬单也涨了名气")。

### 8.3 挖角

- 目标:任意其他玩家院系中已镶嵌的人才。
- 费用:该人才牌面底价 ×150%，**向上取整到整数资源单位**后支付给银行；同时被挖方从银行获得牌面底价 50% 的补偿金，**向下取整**。例如底价 7 的顶尖人才，挖角费为 11，被挖方补偿 3。
- **防御**:被挖方可立即支付 1🏛 宣布"服务期未满",本次挖角无效(费用退还);核心院系首次防御免费(§7.4);每名人才只能被同一玩家尝试挖角一次/时代。
- 事件牌「人才流动禁令」生效期间,禁止对中西部/东北区位学校发起挖角。

## 九、时代事件系统

### 9.1 事件牌构成

每张事件牌注明:**生效范围(门类/区位/全体) + 效果 + 持续时间(即时 / 本时代 / 永久)**。

### 9.2 设计铁律

1. **每张负面事件必须附带一个"逃生口"**——受灾方获得某种补偿选项(免费拆分、补贴、转型折扣),保证玩家永远有事可做,而不是干挨打。
2. 每时代 12 张牌中,**利好:利空:规则改变 ≈ 5:4:3** ⚙。
3. 事件强度随时代递增:第 1~2 时代事件影响 ±1 产出,第 5~6 时代可达 ±2 产出或改变计分规则。
4. 除新工科外,各门类在整个事件库中的"被打击次数"与"被利好次数"应大致均衡;**新工科例外**——它的事件以利好开局、内卷收尾,呈现完整的赛道生命周期。

### 9.3 事件的可预测性(信息博弈)

- 每个时代堆顶的下一张牌**背面印有门类色带**(只显示涉及哪个门类,不显示吉凶)——所有人都能看到"下个十年信息学科有大事",但不知道是崛起还是寒冬。
- 「政策公关」行动(2🏛)可以偷看牌面。得到的信息可以说、可以不说、可以说假话。

## 十、联盟与外交

### 10.1 高校联盟

- 由 2~3 名玩家签订,双方各付 1🏛,联盟以**一个时代**为期,到期自动解散,可续签。
- 联盟效果(签订时二选一):
  - **资源互通**:预算阶段,盟内每人可将 2 单位资源按 1:1 换成另一种资源(与盟友银行式互换);
  - **联合培养**:盟内全体生源力 +1(持续)。
- 盟内调档优惠:盟友间发起调档免 2🏛 调档费(联合办学的信任基础)。
- 一名玩家同时只能加入一个联盟。联盟不共享胜利——**声望没有联盟结算,登顶者只有一个**。

### 10.2 国家重大工程：五赛道并行(v0.5)

#### 10.2.1 项目池与立项

- 共 **60 张国家重大工程牌**，6 个时代各 10 张。
- 每时代 10 张牌分成五条赛道，每赛道 2 张：**基础科学 / 工程技术 / 生命资源 / 人文治理 / 交叉战略**。
- 3~4 人局：每时代基础科学、工程技术、生命资源、人文治理各随机翻开 1 张，共 **4 个开放项目**。
- 5~6 人局：在上述 4 个项目之外，再从交叉战略赛道随机翻开 1 张，共 **5 个开放项目**。
- 每名玩家每时代最多成为 **2 个工程**的有效竞标单位成员；联盟合标也计入该上限。该限制迫使玩家选择国家战略方向，避免“每个项目都撒一点资源”。
- 时代事件若指定某个工程立项，则指定工程优先；它替换本时代同赛道原本随机翻开的项目。若 3~4 人局指定 E 交叉战略项目，则以该项目替换 B 工程技术项目，避免临时增加第 5 个项目并抬高 AP 压力。

#### 10.2.2 门类资格与空档期保底

每张工程拥有**主门类、协同门类**：

- 拥有至少 1 个主门类院系：具备**主导资格**，正常竞标并可获得完整牵头奖励；
- 只有协同门类院系：正常竞标、正常分声望；若最终第 1，牵头奖励中的永久平台效果改为对应牌面的即时资源补偿（不获得永久平台）；
- 主门类和协同门类都没有：仍可作为**社会协作单位**参与，只允许 `3💰=1 有效出资点`，不能使用工程倍率，也不能获得牵头奖励。

因此专精学校的匹配优势明显，但不会因为某十年没有完全对口项目而彻底退出工程系统。

#### 10.2.3 竞标与结算

- 每名玩家在事件与立项阶段有 **1 次初始申报机会**：只要自己具有该项目主门类或协同门类资格，即可不花 AP 向一个开放项目投入至少 1 个有效点；联盟成员可把各自的机会投入同一联盟竞标单位。
- 若自己对本时代**全部开放工程均无主/协同匹配**，可改用一次零匹配保底：不花 AP，按社会协作单位规则向 1 个工程投入至少 `3💰=1 有效出资点`；仍无牵头资格、不能使用倍率。只要存在至少 1 个匹配工程，就不能使用此保底。
- 行动阶段执行行动 #10 时，可新参加第 2 个工程、向已参加工程追加资源，或在此前放弃初始申报时花 AP 启动第 1 个工程。同一时代可多次追加。
- 玩家可独立投标，也可联盟合标；联盟按成员实际出资比例拆分所得声望。
- 每种资源必须按牌面折算率凑成完整一组后才能投入（例如 `2💰=1点` 时，💰须以 2 的整数倍投入）；不同资源可以混合投入。
- 每个开放项目在阶段④**独立结算**。按有效出资点排名，仅前两名分得牌面基础声望池；第 1 名获得 `向上取整(声望池 × 第1有效点 / 前二有效点总和)`，第 2 名获得剩余声望，保证声望均为整数且总和不变。第 1 名获得牵头奖励，第 2 名获得参与奖励。
- 联盟所得声望再按成员实际投入折算出的有效点使用同样方法分配；若有余数，依次给实际贡献较高者，仍平手则给生源力较高者。固定有效点只帮助联盟竞标单位排名，不归属某位成员。
- 若某项目只有 1 个有效竞标单位，该单位仍可完成项目，但基础声望池**减半（向上取整）**，只获得牵头奖励，防止无人竞争项目成为免费刷分点。
- 前两名实际投入全部消耗；其他竞标单位返还 50% 实际投入（逐种资源向下取整）。
- 平手依次比较：主门类最高等级院系 → 协同门类最高等级院系 → 生源力 → 较早达到该出资额者。

#### 10.2.4 工程倍率统一规则

- 同一竞标单位同时拥有多个“×倍率”时，**只取最高倍率，不相乘**；
- 常规工程倍率最高 **×1.5**；
- 只有明确写有“可突破工程倍率上限”的唯一高校能力可达到 **×1.75**；
- 政策牌、人才、项目平台或高校技能提供的“+N 固定有效出资点”在倍率计算完成后加入，**固定点不能再次被倍率放大，且所有来源合计每个竞标单位在单个项目中最多 +2 固定有效点**。超出部分忽略。

该规则替代旧版可能出现的 `×1.5 ×1.25 = ×1.875` 等叠乘方式。

60 张具体工程、时代锚点和差异化奖励详见《高校风云/高校风云-国家重大工程牌全库.md》。

### 10.3 政策牌市场(v0.4)

- 开局洗混 24 张政策牌，翻开 **4 张**形成公开政策市场。
- “购买政策牌”消耗 1 AP；支付牌面 🏛 费用后将牌拿入手中，并立即补满市场至 4 张。
- 每时代结束时弃掉市场中最左侧 2 张旧牌并补满。每名玩家政策牌**手牌上限 3 张**。
- 政策牌分为四类:
  - **即时**:自己的行动轮使用，不消耗 AP；
  - **反应**:牌面触发条件发生时使用；
  - **持续**:正面放置，本时代结束弃置；
  - **常设**:持续生效；每名玩家最多同时保留 1 张常设政策。
- 除牌面另有说明外，同一时点每名玩家最多使用 1 张政策牌，防止反应链与爆发连锁。
- 政策牌的核心定位是**改变规则、时机、风险和资源用途**，而不是另一套“🏛直接换⭐”商店。24 张完整牌库见《高校风云/高校风云-政策牌全库.md》。

### 10.4 交易的边界

- 可交易:院系(仅经由 §7.6 调档流程)、经费、政策牌、口头承诺。
- 不可交易:声望、生源力、认证标记、核心院系、人才单独转让(人才只随院系走或被挖角)。
- **口头承诺不具约束力**。规则不惩罚背信,声誉自会惩罚。

## 十一、学科评估与声望

### 11.1 评估阶段流程与智库通道(2010 / 2030 / 2050)

> **智库通道(每时代一次,不占 AP)**:拥有至少 2 个文/法/商/农院系的玩家,可在自己的行动轮将至多 2🏛 转为等量 ⭐。可以转换 1 或 2,未用额度不能跨时代累计;使用后翻面本校的智库标记,时代推进时重置。

1. 按 8 个门类逐一结算(**只结算至少有两名玩家拥有院系的门类**,无人竞争的门类跳过,加快节奏)。
2. 每门类内,比较各玩家该门类**全部院系强度之和**。
3. **分档计分(v0.3)**:

| 门类档 | 门类 | 第 1 名 | 第 2 名 |
|---|---|---|---|
| **重点档** | 理、医、传统工科、新工科 | **+5⭐** + 认证 | +3⭐ |
| **常规档** | 文、法、商、农 | **+4⭐** + 认证 | +2⭐ |

4. 门类第1名获得认证时，从自己该门类院系中选择 **1 个尚未认证的院系**放置认证标记：该院系永久强度 +1，且该认证使学校以后每个预算阶段 +1💰。同一院系最多1枚；若该门类所有院系均已认证，本次不再获得新标记。
5. 平手时并列者均按高位声望奖励发放，但只有生源力更高者有资格获得本次认证；若其该门类已无可认证院系，则认证空缺，不顺延给另一并列者。

> **常规档补偿四件套**(防止路线单一):① 文/法/商/农建造费 −1💰;② 升级时 🏛 可替代 🔬;③ 智库通道可把政策力转为声望;④ 非理工国家级工程通常竞争者更少，且奖励更偏资源、政策与长期能力。理工单次计分与工程声望上限更高但竞争更激烈,常规档靠低成本、政策循环、差异化工程奖励和稳定得分追平期望收益。

### 11.2 全局结算(评估阶段附加)

- **综合奖**:本次评估中拿到"门类第 1"个数最多的玩家,额外 +3⭐(综合性大学奖励)。
- **精尖奖**:若某玩家仅有 ≤3 个门类但全部进入前 2,额外 +3⭐(特色型大学奖励)。
- **人文底蕴奖**:在文、法两门类均进入前 2 的玩家,额外 +3⭐。
- 综合奖与精尖奖互斥;人文底蕴奖可与二者叠加。

### 11.3 声望来源总表 ⚙

| 来源 | 声望 | 频率 |
|---|---|---|
| 评估重点档第 1 / 第 2 | +5 / +3 | 每次评估,每门类 |
| 评估常规档第 1 / 第 2 | +4 / +2 | 每次评估,每门类 |
| 综合奖 / 精尖奖 / 人文底蕴奖 | +3 | 每次评估 |
| 国家重大工程 | 每个开放项目的前二按份额瓜分牌面基础声望池 **4~8⭐**，并获得差异化附加奖励 | 每时代开放4张（5~6人局5张），每人最多参与2张 |
| 智库通道 | 最多 +2 | 每时代一次 |
| 院士/学部委员入职 | +2 | 即时 |
| 院系升至等级Ⅲ | +2 | 即时 |
| 文科底蕴(等级Ⅱ+文科院系) | +1 | 每次评估 |
| 事件奖励 | 事件牌面值 | 随机 |
| 高校技能 | 各校不同 | — |
| **声望损失**(挽留院系 −1/次、丑闻类事件、院士被挖) | −1~−3 | 主动 / 随机 |

> **v0.7 暂定基线 ⚙**：在 60 张国家重大工程、单项目 4~8⭐、每人每时代最多参与 2 项、农Ⅰ强度 2 的结构下，系统模型推荐胜利线 **112 / 86 / 80**。最终 5000 局复验三档胜率约 **33.6% / 32.7% / 33.6%**，提前登顶率约 **23.1%**。模型显示政策牌平均效力上下浮动 25% 对整体结果影响有限；完整人才并不是声望膨胀主因；农科问题主要是旧Ⅰ级低成本插卡套利而非完整农业路线过强；新工科Ⅲ强度 8 暂未显示系统性超模。以上仍需真人局验证，详见《模拟报告-v0.7》。

## 十二、胜利条件

### 12.1 即时胜利:登顶世界一流

任意时点(即时效果结算完毕后)有玩家声望达到本校档位胜利线——**领跑 112 / 劲旅 86 / 蓄力 80** ⚙——游戏立即结束,该玩家获胜。多人因同一效果同时达成时,比较`声望 − 自身胜利线`;仍平手依次比较生源力 → 认证标记数 → 剩余经费。

### 12.2 2050 结算胜利

进行完 2040s 时代(含 2050 年最终评估)后若无人登顶,计算每人的**相对成就值 = 声望 − 自身胜利线**,数值最高者获胜(允许为负数)。平手依次比较:声望绝对值 → 认证标记数 → 等级Ⅲ院系数 → 剩余经费。

### 12.3 专项称号(非胜利,写入战报)

- **学术泰斗**:累计学术点产出最高
- **人才摇篮**:生源力峰值最高
- **国之重器**:国家重大工程实际出资总额最高
- **逆势崛起**:声望相对开局的**增幅**最大(蓄力档学校的主战场)
- **时代弄潮儿**:受利好事件影响次数最多
- **中流砥柱**:成功挽留(熬到流拍)院系次数最多

### 12.4 变体:1980 开局(长局)

时代改为 7 个(1980s 起),追加"1980s 事件堆"(恢复高考余波、出国潮、乡镇企业崛起等),三档胜利线各上调 15,即**领跑 127 / 劲旅 101 / 蓄力 95** ⚙,时长约 +30 分钟。适合熟练玩家。

### 13.2 每校设计模板

```
【学校名】 区位:__  档位:__
核心门类:__、__(该门类院系享 §7.4 核心保护)
开局院系:__(从核心门类中取)
特色技能:一条改变规则的能力(不是单纯数值加成)
风味约束(可选):一条自我限制,换取技能强度
```

技能设计三原则:
1. **改规则,不改数值**——"竞标航天类工程出资视为 ×1.5"优于"经费 +1"。
2. **只扬长,不揭短**——技能来自该校公认强项与正面文化梗;自嘲梗仅限该校学生自己广泛传播的范围。
3. **档位内互相平衡,档位间靠 13.1 的系统修正平衡**。

### 13.3 选校模式

- **轮抽(标准)**:每人 3 选 1。
- **征召(竞技)**:公开 10 校,按逆声望顺序选择。
- **指定(教学)**:推荐使用附录 C 的 11 校组合(覆盖三档与全部五区位)。

- **「聚变点火成功」**(利好/理、新工科):对应院系产出 +2;本时代国家重大工程的基础科学赛道直接指定“可控核聚变示范堆点火”。
- **「少子化浪潮」**(利空/全体):所有人生源力 −2。逃生口:文/法院系每个抵消 1 点损失("生源少了,更拼内涵")。

| 领先者滚雪球 | 评估奖励固定值;蓄力档翻倍机制;「大改革」类事件重洗口径 |
| 谈判超时 | 2 分钟沙漏;调档每时代限发起一次 |

### B.3 数值校准优先级

1. 声望曲线(11.3 粗算校验)——决定游戏时长与结局分布;
2. **重点档 vs 常规档的期望收益比**(目标:考虑竞争烈度后,两条路线胜率差 <10%);
3. 调档三参数:目标刻度 3 / 加急 2💰 / 挽留 1⭐——挽留的声望代价是全游戏最敏感的数值;
4. 院系造价 vs 产出回收期(目标:2 个时代回本 ⚙);
5. 新工科解锁节奏(每时代 2 张是否恰当);
6. 三档开局的实际胜率(模拟目标:各档胜率差 <10%;修正后的 v0.6 基准结果差 2.3%;真人局继续记录)。

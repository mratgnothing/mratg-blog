博客已经一个多月没有认真更新，偏偏这一个月又是项目最密集的一段时间。今天开始补历史时，我不想只凭聊天记忆写“最近做了很多事”，于是把 ChatGPT 的长期上下文和 Codex 本地会话放在一起，对照项目 Git 记录重新建时间线。

筛选规则也定得比较严格：主会话当骨架，guardian 和 subagent 只用来验证结果；真实发生日期保留；已经写过的事情不重复；密钥、账号、本机路径和私人信息在进入博客前全部过滤。

这次补写本身也成了一个新的工作流：历史对话负责找线索，本地记录负责证明事情真的发生过，`content-inbox` 负责导入，构建和 Git diff 负责最后把关。以后如果能定期跑，就不用再隔一个月做一次“数字考古”了。

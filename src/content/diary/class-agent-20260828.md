最近把 QQ 的读取、回复、文件收发能力重新整理了一遍，顺手又往前走了一步：给重复的班务工作做一个长期 Agent。

我不希望它变成一个自动替我发消息的机器人。更合适的角色是先帮我查通知、找文件、整理提交情况、核对节点，把真正需要判断和对外发送的部分留给我。

以前觉得 Agent 最重要的是“能做多少事”，现在越来越觉得“知道哪些事不能擅自做”同样重要。校园事务很碎，但也刚好适合用这种方式一点点结构化。

# 中国高校殺：固定牌桌与首页入口

日期：2026-09-06。

游戏正式命名为《中国高校殺》。保留既有网址、API、会话存储键和历史规则文件路径。项目基线同步名称，历史牌库与规则内容不做机械替换。

## 页面变化

- 桌面端对局固定在浏览器视口内：顶部对手，中央国家工程，底部本人校园；右栏使用决策、市场、校史、牌库四个标签。
- 对手校园用弹窗查看，事件和调档放入校史。本人院系显示当前强度。卡牌选择后自动打开决策标签。
- 手机底部切换牌桌、校园、决策/市场。详情区和超量卡牌可局部滚动；桌面整页不滚动。支持全屏、键盘标签导航和减少动画偏好。
- 首页增加 `GameFeature.astro` 独立模块，提供真人匹配和 AI 对战入口；网址参数优先于已保存的模式。主导航「游戏」链接至首页模块。
- 标题使用霞鹜文楷本地 WOFF2 子集，5,832 字节，包含「殺」。来源：https://github.com/lxgw/LxgwWenKai ，OFL 许可随字体发布。正文和交互使用系统字体，卡牌标题使用楷体回退。

- `npm.cmd run build`：114 个页面构建通过。
- `npm.cmd run test:gaoxiao`：18 项测试通过，含 192 局完整自动对局、26,371 次合法行动。
- `node scripts/test-gaoxiao-table.mjs`：构建产物通过 Astro preview 展示，本地 API 请求转发到实际 Wrangler Worker；两个独立浏览器匹配成 2 真人 + 2 AI，双方均执行行动，刷新恢复席位。
- 验证四种标签、院系/人才市场、档案搜索、本人操作、对手详情弹窗、退出返回大厅。
- 1366×768、1920×1080 的 4/6 人桌无整页横向和纵向溢出；390×844 手机三个视图和首页模块无横向溢出。

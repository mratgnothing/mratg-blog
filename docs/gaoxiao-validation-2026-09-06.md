## 边界

上述结果验证的是 `quick-v1` 快速版；完整实体规则中的复杂技能、政策、人才拍卖等尚未全部自动化，差异见 `gaoxiao-online.md` 和游戏页的“开局须知”。312 局自动测试不等价于真人平衡性或趣味性验证。

本次核对 GitHub 最新提交为 `e63d0e49520292d4d624b8d1b199b5ddd591d80b`，与复制的原网站仓库一致。开发位于独立 `online-ai` 目录，未覆盖 `site-work` 的未发布草稿，也未修改 `D:\GitHub\mratg-pixel-blog-astro` 的工作树。

- Worker：`mratg-gaoxiao-game`，版本 ID `9d3c7e03-f852-4f5d-95e5-adc1ba198240`，路由 `mra-t-g-blog.cn/api/gaoxiao/*`，health 返回 1.1.0。
- Pages：`8b30efe0.mratg-pixel-blog-git.pages.dev`，正式域名 `https://mra-t-g-blog.cn/games/gaoxiao-fengyun/` 返回新页面与 `online.js?v=1.1.1`。
- 真人身份：AI 对战中的本人始终保留 `human=true`、`auto=false`；旧 room 中尚未离席的真人 auto 状态会在获取状态时自动恢复。
- 思考时段：AI 对战无强制操作超时；真人匹配基础思考时段 5 分钟，在线自动延长，离线超时仅代走一次。AI 每步 2.5 秒，新时代发牌过渡 5 秒。
- 准备确认：真人明确点击准备，全部就绪后开局；AI 对战中未准备时不会擅自推进。
- 生产真人停留测试：真实 Edge 浏览器停留本人回合 100 秒后，仍显示“自由思考”，按钮可用，随后出牌成功。结果在 `output/playwright/v2/production-human-100s.json`。
- 修复线上较高延迟下“刚出牌就退出”的点击丢失：请求进行中禁用退出确认，完成后恢复；迟到的轮询不能把已退出房间显示回来。
- 前端审查：线上旧版存在标题被导航覆盖、页面过长、本人/对手身份不突出。新版入口改为双模式卡，牌桌集中展示对手、工程和事件，本人校园独立标记，手机提供三项快捷导航。修复事件标题在纸色卡牌上的低对比度及按钮悬停对比度。
- 截图位于 `output/playwright/v2/`，当前在线浏览器全流程运行结果以其中 `result.json` 为准。
